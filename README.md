# discord.fun

⚡ **Discord Utility Tool**  
> A collection of tools for automating and interacting with Discord. Use responsibly.  

## Features
- Custom status changer  
- Friend/message automation  
- Server/channel management  
- Webhook spamming (handle with care)  
- And more…

> **Note:** This tool is for educational purposes and testing in controlled environments only. Misuse can violate Discord's Terms of Service.

## Installation
1. Clone the repo:  
   ```bash
   git clone https://github.com/yourusername/discord.fun.git
    ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```
3. Run the tool:

   ```bash
   python main.py
   ```
